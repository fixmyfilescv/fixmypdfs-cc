Safety

Is FixMyPDFs safe?

Yes. Your PDFs never reach us: every tool runs inside your browser, in the same sandbox that keeps any website away from the rest of your computer. 0 bytes of your files are transmitted — the Network tab will show you.

Updated September 18, 2026

Your PDFs stay with you

Online PDF tools normally upload your file to their server, process it there and let you download the result. Even with good intentions, that leaves a copy on a machine you don’t control, for a time you can’t check.

FixMyPDFs skips the server. The file is read, changed and saved on your own device, so there’s no copy to leak, sell or forget to delete. The no upload page shows how to confirm it with your browser’s developer tools or by turning off your internet.

Nothing to install, nothing to sign up for

  • No downloads to run. Everything happens in a normal browser tab, which can’t reach your other files or apps.
  • No account. We never ask for an email address or a password, so there is nothing to leak.
  • No ads. The only third-party script is Microsoft Clarity, which counts visits and is blocked from reading the tool area, so it never sees your documents or their names.

What the page can and can’t do

A web page can only read the files you choose to give it, and only while the tab is open. It can’t browse your folders, see other tabs or run anything outside the browser. When you close the tab, the PDFs it was working on are gone from memory.

The page stores a few preferences in your browser, such as dark mode, and the engines it has downloaded so they work offline. None of that includes your files or anything about them. Passwords you type into the lock and unlock tools are used once, in memory, and never stored.

Built on well-known open-source code

The heavy lifting is done by long-established open-source projects: pdf.js from Mozilla, pdf-lib, qpdf and Tesseract. Each is listed on the licenses page, and the architecture is explained on how it works.

Staying safe with any PDF site

  • Check where the file goes. Open the Network tab before you add a sensitive document, on any site.
  • Redact, don’t cover. A black box drawn in an editor hides text on screen but leaves it in the file. Use a tool that removes it.
  • Strip metadata before sharing. Author names, company names and file paths travel inside PDFs. Remove PDF Metadata clears them.
  • Be wary of “free” tools that ask for an email before giving you the file back. Your document was the price.

Questions

Is FixMyPDFs legit?

It is a free set of PDF tools that runs in your browser. There is nothing to install, no account, and no file is sent to us, which you can verify with the steps on the no upload page.

Is it safe to put a bank statement or passport scan through it?

Yes — those are the files it’s built for. The PDF never leaves the browser tab, and nothing is kept after you close it.

Can a PDF from here contain a virus?

The output is built on your device from the file you gave it. It can’t pick up anything that wasn’t in your original. Tools like Flatten PDF go further and remove scripts and form actions from the file.

Is redaction here actually permanent?

Yes. Redact PDF removes what’s under each box from the saved file, instead of drawing a black shape on top — the mistake behind most leaked “redacted” court filings.

How does FixMyPDFs make money?

It doesn’t need to make much: your device does the work, so there are no processing servers to pay for. There are no ads and nothing to sell — the only script from anyone else is Microsoft Clarity, which counts page visits and is blocked from the tool area.
