    Why it doesn’t upload

    The PDFs people check before an upload are the sensitive ones: a passport scan for a visa form, a CV, a tax return for a government portal. Checking them doesn’t need a copy anywhere else, so the file is read here, in your browser tab, and goes to exactly one place — the form you choose.

    Worth knowing

    • It checks what a PDF can be tested for — size, pages, encryption, text, fonts, fields and name. A portal can still refuse a file for its content, like a blurry scan or the wrong document.
    • Portals disagree on what a kilobyte is. Sizes here use 1 KB = 1,000 bytes, the stricter reading; a file within 2.4% of a KB limit is flagged so you can leave a margin.
    • The destination limits are the ones each service publishes. A specific exam or government form can set its own — when the form states a limit, type that one in.
    • Font checks see whether a font is stored in the file, not whether it has every character your text uses.

    Under the hood

    What happens to your file

    The file’s size is its exact byte count, compared with the limit in SI units (1 KB = 1,000 bytes) and flagged when it would only pass with 1,024-byte kilobytes. Encryption is detected with pdf-lib, page sizes and fonts are read from the page and font dictionaries, and pdf.js reads each page’s text to find scans. The file isn’t changed.

    Questions

    How do I check the size of a PDF in KB?

    Drop it here. The exact size shows at once in KB and in bytes — 184 KB (184,320 bytes) — so you can compare it with the limit on the form without guessing from a rounded number.

    Why does the portal say my PDF is too big when it looks under the limit?

    Some systems count 1 KB as 1,024 bytes and others as 1,000, and file managers round. A 204 KB file passes a 200 KB limit in one and fails in the other. This checker flags files that close, so you can shrink them a little.

    Will a scanned PDF be accepted?

    Usually, yes — most forms only care about size and type. But applicant tracking systems can’t read a scanned CV, and some portals ask for a “text-searchable” PDF. The checker tells you when a file is a scan, and links to the tool that makes it searchable.

    What else makes an upload form reject a PDF?

    A password on the file, encryption restrictions, fillable form fields, scripts or attachments inside, very long file names or names with symbols, and too many pages. Each one is checked here, with its fix.

    My PDF is too big. How do I make it fit?

    Press Compress it to fit in the result. It opens Compress PDF — already set to the destination you picked — which shrinks the file just enough and keeps the text sharp where it can.
