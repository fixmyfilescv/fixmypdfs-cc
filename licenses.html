Open-source licenses

FixMyPDFs stands on excellent open-source work. These are the libraries that run in your browser when you use the tools, with what each one does and the license it is published under.

Updated September 18, 2026

Library What it does here License
pdf.js (Mozilla) Reading, rendering and extracting text from PDF pages Apache-2.0
pdf-lib (@cantoo/pdf-lib) Editing PDF structure: merging, splitting, stamping, forms and creating PDFs MIT
@cantoo/fontkit Embedding and subsetting fonts in the PDFs we write MIT
qpdf (via qpdf-wasm) AES-256 encryption, removing passwords and restrictions, repairing damaged files WebAssembly build by neslinesli93/qpdf-wasm, distributed unmodified. Apache-2.0 (qpdf) and ISC (wrapper)
Tesseract.js and tesseract.js-core On-device OCR for scanned PDFs Apache-2.0
Tesseract language models (tessdata best_int) The trained models OCR PDF reads English, Spanish, Portuguese, French, German and Indonesian with Apache-2.0
docx Writing Word documents for PDF to Word MIT
mammoth Reading Word documents for Word to PDF BSD-2-Clause
ExcelJS Reading and writing Excel workbooks MIT
PptxGenJS Writing PowerPoint files for PDF to PowerPoint MIT
marked Reading Markdown for Markdown to PDF MIT
highlight.js Highlighting code blocks in Markdown and HTML BSD-3-Clause
DOMPurify Cleaning HTML before it is laid out as a PDF MPL-2.0 or Apache-2.0
jSquash (JPEG, WebP, AVIF) Recompressing images inside PDFs Apache-2.0
heic-to Reading iPhone HEIC photos for Images to PDF LGPL-3.0
UTIF.js Reading TIFF scans MIT
fflate ZIP archives, EPUB packaging and stream compression MIT
Noto Sans, Noto Serif and Noto Sans Mono Fonts embedded in PDFs we create SIL Open Font License 1.1
Caveat, Indie Flower, Kalam, Homemade Apple, Dancing Script, Great Vibes Handwriting and typed-signature fonts SIL OFL 1.1 (Homemade Apple: Apache-2.0)
Kokoro-82M (hexgrad) and kokoro-js The natural reading voices in PDF to Audio The model is downloaded from Hugging Face on first use, unmodified. Apache-2.0
Transformers.js (Hugging Face) Running the voice model in the browser Apache-2.0
ONNX Runtime Web (Microsoft) The WebAssembly engine the voice model runs on MIT
phonemizer (with eSpeak NG) Turning text into the sounds the voice speaks eSpeak NG compiled to WebAssembly by the phonemizer package, distributed unmodified. Apache-2.0 (wrapper) and GPL-3.0 (eSpeak NG)
lamejs (@breezystack/lamejs) Encoding MP3 files in PDF to Audio LGPL-3.0
Astro and Tailwind CSS Building the website MIT

Source code for GPL and LGPL components

libheif (LGPL-3.0, inside heic-to), eSpeak NG (GPL-3.0, inside phonemizer) and lamejs (LGPL-3.0) are shipped as the unmodified builds published by the projects linked above, where their complete source code is available. lamejs is loaded as its own file, so it can be replaced. If you would like us to send you the corresponding source for the exact versions we distribute, email hello@fixmypdfs.cc and we will provide it, free of charge, for at least three years from the date the version was last served.

Fix your PDFs. Free. In your browser.

Powered by pdf.js, pdf-lib and qpdf compiled to WebAssembly, running inside your own browser. Free, with no ads, and it will stay that way — if it saved you a job, you can chip in.
