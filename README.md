## ✨ Features & Advantages

* **🔒 100% Client-Side Privacy:** Your sensitive documents never leave your browser. All computations run locally via modern WebAssembly engines.
* **⚡ Zero Upload Latency:** Instant processing with no waiting for large files to upload to an external server.
* **📱 Cross-Platform Support:** Works seamlessly across macOS, Windows, Linux, iOS, and Android.
* **📶 Offline Ready:** Progressive Web App (PWA) functionality allows you to use tools even without an active internet connection.

## 🛠️ Built With
