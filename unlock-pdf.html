    Why it doesn’t upload

    Restricted PDFs are usually the formal ones: contracts, reports, course material. Unlocking them in your own browser means the document is never copied to someone else’s server just to switch on the Print button.

    Check it in your browser’s Network tab

    Worth knowing

    • Only for PDFs you own or have the right to use this way. Restrictions are often a publisher’s license terms.
    • If the file also has an open password, you need to know it.
    • The unlocked copy has no restrictions and no encryption.

    Under the hood

    What happens to your file

    Some PDFs open without a password but set an owner password that asks viewers to block printing, copying or editing. qpdf rewrites such a file without those restrictions. A file that needs a password to open is a different case: use Remove Password, with the password.

    Runs on qpdf

    Reference: qpdf manual

    Questions

    What are PDF restrictions?

    Settings saved with an “owner password” that tell PDF readers to block printing, copying, editing or form filling. The file still opens without a password — the reader just grays out those buttons.

    How do I remove printing restrictions from a PDF?

    Drop it here and press Remove restrictions. You get a copy with printing, copying and editing allowed — no password needed for restriction-only files.

    Is this different from removing a PDF password?

    Yes. An open password stops the file opening at all; Remove PDF Password handles that and needs the password. Restrictions only limit what you can do once it’s open.

    Why can’t I copy text from my PDF?

    Either copying is restricted — which this removes — or the page is a scanned image with no text in it at all, which needs OCR instead.
