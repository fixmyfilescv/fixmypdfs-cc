    Why it doesn’t upload

    A production is privileged and confidential material by definition: medical records, contracts, internal email. Here it is numbered inside your browser tab and never passes through a third party’s server, so there is no processor to list in a protective order and no copy to ask anyone to delete.

    Check it in your browser’s Network tab

    Worth knowing

    • Every page of every file is numbered. To leave a slip sheet unnumbered, take it out of the file first and number it separately.
    • The number is drawn on top of the page. If something is already printed in that corner, pick another position or turn on the white box.
    • This numbers pages; it doesn’t endorse them with confidentiality legends. For a CONFIDENTIAL line on each page, use Headers & Footers or Add Watermark.
    • Files that ask for a password when they open have to be unlocked first, because each file is rewritten.
    • Your court or the parties’ agreement may set the format. Check the protocol for prefix, digits and position before you produce.

    Under the hood

    What happens to your file

    Each page gets its label (prefix, zero-padded number, suffix) drawn as real text with pdf-lib, in the corner you choose on the page as displayed. Files are numbered in the order listed, and the count carries from the last page of one file to the first of the next; the index CSV is built from the same count, so it always matches the pages. The white box, if chosen, is a filled rectangle drawn under the number, over the page.

    Questions

    What is Bates numbering?

    A unique number stamped on every page of a set of documents — SMITH000001 to SMITH004210 — so any page can be cited exactly in a legal case or an audit. Unlike page numbers, the count runs on across every file in the set.

    How do I add Bates numbers to a PDF for free?

    Drop the PDFs here, set a prefix and the first number, and press Add Bates numbers. The numbers are written into each page as text, so they print and can be searched, with no Acrobat, account or watermark.

    Can the numbering continue across several PDFs?

    Yes, that’s the default. Put the files in production order with the arrows; the first page of each file takes the number after the last page of the one before. The index shows every file’s range.

    How do I continue from an earlier production?

    Type the next unused number in First number. If the last production ended at ABC001250, start this one at 1251 with the same prefix and digits.

    Are the Bates numbers searchable?

    Yes. They are real text in the PDF, so searching for ABC000123 in any viewer jumps to that page.
