Questions

Are my PDFs uploaded anywhere?

No. Every tool runs inside your browser tab with pdf.js, pdf-lib and WebAssembly. There is no upload server to send a file to. The counter in the header shows the bytes this page has sent, and it stays at 0 — open your browser’s Network tab to check it yourself.

Is FixMyPDFs really free?

Yes: no watermark, no sign-up, no daily cap and no ads. Your device does the work, so there is no server bill to pass on to you.

Is there a file size limit?

No fixed limit. The ceiling is your device’s memory: desktop browsers handle PDFs of several hundred MB, phones somewhat less. Nothing is refused for being too big.

Does it work offline?

Yes. Once a tool’s page has loaded, you can switch off Wi-Fi and it keeps working. Install it as an app and it opens offline too — see using it offline.

Can I redact or unlock a PDF safely here?

That’s what this site is built for. Redact PDF removes text rather than covering it, and Remove PDF Password needs the password once and never sees a server. Sensitive files are exactly the ones that shouldn’t be uploaded to be fixed.

How is this different from iLovePDF or Smallpdf?

Those services upload your PDF, process it on their servers and send it back, and meter the free tier. FixMyPDFs does the same jobs on your device, with no quota. The alternatives pages compare them honestly, including what they do better.
