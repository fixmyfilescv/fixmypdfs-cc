    How to add a header and footer to a PDF

    1. 1

      Add your PDFs

      Drop the PDF, or several: each one is counted from its own first page.

    2. 2

      Check the settings

      Type the header and footer. A bar splits the text across the page — “Confidential | Page {page} of {pages}” puts one at each edge — and {date} and {file} fill themselves in.

    3. 3

      Save the result

      Save. The text is written into every page as real text, so it prints, can be searched, and looks the same in every viewer.

    Why it doesn’t upload

    Headers usually go on documents that are about to be sent somewhere formal: a report to a client, a submission, a board pack marked Confidential. The words are added here in your browser tab, so the document is never held on someone else’s server while it happens.

    Check it in your browser’s Network tab

    Worth knowing

    • Headers and footers are drawn on top of the page. If the page already has text in that strip — an old footer, a letterhead — move yours with Distance from the edge, or white the old one out first with Edit PDF.
    • Text too long for the page’s width is made smaller to fit rather than cut off, so keep a header to a short line.
    • {date} is today’s date on this device, written once. It doesn’t update when the file is opened later.
    • Chinese, Japanese and Korean characters aren’t in the fonts yet and would come out as empty boxes.
    • A PDF that asks for a password when it opens has to be unlocked first, because the file is rewritten.

    Under the hood

    What happens to your file

    The header and footer are drawn onto each page with pdf-lib as real text, at the left, center or right of the page as it is displayed — a page stored sideways with a /Rotate entry still gets them at its visual top and bottom, reading the right way up. {page} and {pages} are counted over the pages that get a header, and {date} is fixed when you save. Plain Latin text uses a standard PDF font that is not embedded; other scripts use a subset of Noto. Nothing else in the file changes.

    Runs on pdf-lib

    Questions

    How do I add a header and footer to a PDF without Acrobat?

    Drop the PDF here, type the header and footer, and press Add header and footer. The text is written into each page of the file itself, so it shows in every viewer and on paper — no Acrobat, no account and no watermark.

    Can I put text on the left and the page number on the right?

    Yes. Separate them with a bar: Confidential | Page {page} of {pages} puts the first part at the left edge and the second at the right. Three parts go left, center and right.

    How do I add the date to every page of a PDF?

    Type {date} anywhere in the header or footer. It becomes today’s date on every page, in the style you pick under Advanced, from September 29, 2026 to 2026-09-29.

    Can I leave the cover page without a header?

    Yes. Open Advanced and turn on Leave the first page blank, or type the pages that should get one, like 2-30. The {page} count starts on the first page that gets a header.

    What’s the difference between this and Add Page Numbers?

    Add Page Numbers puts one number in one place. This writes a whole line at the top and bottom — a title, the date, the file name, a label — with the page number as one part of it if you want.
